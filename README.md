# Python for Absolute Beginners

Welcome to **Python for Absolute Beginners** – a simple and friendly starting point for anyone who wants to learn Python programming from scratch.

## 📘 About

This project is designed for complete beginners with **no prior coding experience**. It includes a single Python script that covers the core fundamentals of Python through short, clear examples.

Topics included:

- ✅ Printing and comments
- ✅ Variables and data types
- ✅ User input
- ✅ Conditional statements
- ✅ Loops
- ✅ Functions
- ✅ Lists and dictionaries
- ✅ Classes and objects
- ✅ File handling

---

## 📂 Files

- `python_for_absolute_beginners.py` – The main Python script with beginner-friendly examples
- `hello.txt` – A file generated by the script as an example of file writing
